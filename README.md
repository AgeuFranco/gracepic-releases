---

## O que é o GracePic?

Editor e organizador de fotos RAW para Windows. Converta arquivos NEF para JPG, TIFF ou PNG, organize por data e orientação, remova duplicatas — tudo localmente, sem upload para nuvem.

**Gratuito. Sem cadastro. Sem assinatura.**

---

## Download

Acesse [Releases](https://github.com/AgeuFranco/gracepic-releases/releases/latest) e baixe o instalador `.exe` mais recente.

### Requisitos
- Windows 10 / 11 (64-bit)
- ~50 MB de espaço em disco
